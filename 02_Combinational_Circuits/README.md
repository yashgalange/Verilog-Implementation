This directory contains combinational digital circuit implementations using Verilog HDL.

## Implementations

1. 2:1 Multiplexer
2. 4:1 Multiplexer
3. 8:1 Multiplexer
4. 1:2 Demultiplexer
5. 1:4 Demultiplexer
6. 2-to-4 Decoder
7. 3-to-8 Decoder
8. 4-to-2 Encoder
9. 4-to-2 Priority Encoder
10. 2-bit Magnitude Comparator
11. 4-bit Magnitude Comparator
12. Binary-to-Gray Code Converter
13. Gray-to-Binary Code Converter
14. BCD-to-7-Segment Decoder
15. Parity Generator and Checker
