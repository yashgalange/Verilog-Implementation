# Arithmetic and Data Processing Circuits

This directory contains arithmetic circuits and data processing implementations using Verilog HDL.

## Implementations

1. 4-bit Ripple Carry Adder
2. 8-bit Ripple Carry Adder
3. Carry Lookahead Adder
4. 4-bit ALU
5. 8-bit ALU
6. Barrel Shifter
7. Arithmetic Shifter
8. Incrementer and Decrementer
9. Carry Select Adder
