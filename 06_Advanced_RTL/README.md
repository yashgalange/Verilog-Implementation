# Advanced RTL and FPGA Designs

This directory contains advanced RTL implementations and FPGA-oriented digital hardware projects using Verilog HDL.

## Implementations

1. SPI Master
2. SPI Slave
3. I2C Controller
4. CRC Generator and Checker
5. Pipelined Arithmetic Unit
6. Pipelined Multiplier
7. Fixed-Point Multiplier
8. MAC Unit
9. RISC-V Single-Cycle Processor
10. RISC-V Pipelined Processor
11. AES-128 Encryption Engine
12. Systolic Array Processing Element
13. Small Neural Network Accelerator
