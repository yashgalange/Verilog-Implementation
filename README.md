
# Verilog Implementation Journey — Basic to Advanced

A hands-on journey into Digital Logic Design, Verilog HDL, RTL Implementation, Simulation, Debugging, and FPGA-oriented Hardware Design.

## About This Repository

This repository documents my journey of learning and implementing digital hardware using Verilog HDL.

The goal is to develop strong practical skills in:

- Digital Logic Design
- Verilog HDL Programming
- Combinational and Sequential Circuits
- RTL Design and Architecture
- Functional Verification and Testbenches
- Simulation and Debugging
- FPGA-oriented Design
- Advanced Digital System Design

Every implementation is developed step by step, with an emphasis on understanding the hardware rather than simply writing code.

## Learning Roadmap

### Level 1 — Digital Logic Fundamentals
- Basic Logic Gates
- Universal Gates
- Adders and Subtractors

### Level 2 — Combinational Circuit Design
- Multiplexers and Demultiplexers
- Encoders and Decoders
- Comparators
- Code Converters
- Parity Circuits

### Level 3 — Arithmetic and Data Processing Circuits
- Ripple Carry Adder
- Carry Lookahead Adder
- Arithmetic Logic Unit (ALU)
- Barrel Shifter
- Carry Select Adder

### Level 4 — Sequential Circuit Design
- Latches and Flip-Flops
- Registers and Shift Registers
- Counters
- Sequential Logic Systems

### Level 5 — FSM and RTL Design
- Mealy and Moore State Machines
- Traffic Light Controller
- Vending Machine Controller
- UART
- FIFO
- Register File
- PWM Generator

### Level 6 — Advanced RTL and FPGA Designs
- SPI and I2C Controllers
- CRC Generator and Checker
- Pipelined Arithmetic Units
- RISC-V Processor
- AES-128 Encryption Engine
- Systolic Array
- Neural Network Accelerator
